# 启动恢复安全网

> 对应英文原文：[`boot-recovery-net.md`](boot-recovery-net.md)

## 要解决的问题

更新健康门保护“刚应用的新版本”，但设备若直接启动到无法运行关键服务的坏版本，普通回滚可能没有机会执行。启动恢复安全网提供最后退路。

## 组成和触发

systemd 在开机后等待明确截止时间，再读取 active、golden、启动记录和关键服务状态。使用截止时间而不是单个 `OnFailure=`，因为一个服务失败不一定代表整个发布损坏。

判定关注当前是否为受管理发布、关键服务是否健康、更新器是否正在处理、黄金版本是否有效、本启动是否已经恢复过。

## 拒绝触发

证据不足时不动作：没有有效黄金版本、正在合法安装、当前不是受管理发布，或本启动已恢复一次。

## 成员规则和恢复

关键服务集合从发布携带的 unit 推导，避免写死列表。验证黄金版本后原子切换 `current`，写入恢复原因并重启。循环保护保证同一启动链最多恢复一次。

## 测试边界

纯逻辑可测试判定和链接切换；真实 boot/systemd 时序仍需镜像或硬件测试。

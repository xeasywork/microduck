# NPU 与 Microduck 检测器

> 对应英文原文：[`npu-bringup.md`](npu-bringup.md)

## 当前内容

仓库包含单类别 Microduck 检测模型的 ONNX 和 RKNN 版本，以及 `duck-bench` 基准工具。RKNN 使用 RK3566 NPU，ONNX 提供 CPU 回退。

## 运行基准

在板上确认 NPU 驱动和设备节点，使用实际相机或样本帧运行 `duck-bench`，记录加载、预处理、推理、解码、温度和对控制循环的影响。

量化模型输出分数不一定是概率，阈值必须针对量化后的真实结果调节。

## 测量结论

NPU 能承担检测，CPU 回退明显更贵。持续满速检测会产生热负担，因此默认低频检测是资源上限决定，不只是保守偏好。

## 尚缺内容

需要把 `mediad` 原始帧稳定送入检测器、修正相机内参和旋转、把检测结果变成可供行为消费的状态，并在热环境中验证。当前检测通知尚未构成自主行为。

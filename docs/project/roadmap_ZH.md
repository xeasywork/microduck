# 项目路线图

> 对应英文原文：[`roadmap.md`](roadmap.md)

## 当前情况

底层控制、开发通道和主要 `robotd` 已完成；硬件 bring-up 接近收尾；媒体、WebRTC 和 SDK 仍在推进。App、正式模型通道、自主大脑和完整公网访问尚未完成。

## 里程碑

### M1：闭合控制循环 — 已完成

建立关节/IMU 读取、ONNX 推理和电机写入的基本闭环。

### M2：开发通道 — 已完成

建立分支构建、签名、安装和回滚路径，使开发版本能在板卡验证。

### M3：正式 `robotd` — 已完成

分两个 slice 移植控制、安全、API、技能、手柄和运行能力，以不回退旧 runtime 为验收标准。

### M4：硬件 bring-up — 收尾中

解决真实总线、音频、ToF、摄像头、NPU、配对和服务启动问题。

### M5：`mediad`、WebRTC、SDK — 进行中

摄像头和 WebRTC 已能在硬件运行，仍需完善客户端、传输、Agent 入口和权限。

### M6：可交付准备

覆盖普通用户配网、身份、密钥、恢复、同意和发布基础设施。

### M7：知道板卡正在做什么

增强可观测性、诊断、支持包和远程故障定位。

### M8：模型通道

把运动策略从 daemon release 中拆出，在 Hub 独立发布、安装、选择和回滚。

### M9：自主大脑

移植 16 状态行为机，整合心情、探索、ToF、声音、玩球、睡眠、抚摸和社交输入。完成标准是机器人独处十分钟仍有值得观看的自主行为。

## 工作顺序

近期优先模型通道和媒体传输调查；交付相关工作按硬件和供应链周期推进；自主大脑放在更后，先设计再编码。

## 明确不做

项目不会为尚不存在的多硬件版本过早抽象，也不会让外围功能绕过安全与更新原则。

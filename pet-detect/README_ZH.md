# pet-detect：被抚摸音频检测

> 对应英文原文：[`README.md`](README.md)

`pet-detect` 是一个小型音频分类器，用板载麦克风判断机器人头部是否正在被抓挠。机身让麦克风接近“接触麦克风”，抚摸声与普通环境声有明显差异。

运行端通过 `arecord` 获取 16 kHz 单声道 PCM，分类器使用滞回阈值输出 `Start` 和 `End`。`robotd` 可在抚摸开始时播放回应声音。

它不是摄像头模型，也不负责主动蹭人。

## 重新训练

1. 在真机录制抚摸和普通样本。
2. 普通样本覆盖行走、电机、说话和环境噪声。
3. 用 Rust 特征提取器生成与部署端一致的 log-mel 特征。
4. 运行 `training/train.py` 训练小型 CNN。
5. 导出并替换 `models/pet_detect.onnx`。
6. 在板载麦克风上重新标定进入和退出阈值。
